### Plan File Edit Discipline (hard rule)

_~3,900 tokens/session saved_

- Never call `Edit` on `~/.claude/plans/<slug>.md` more than once per user turn.
  Collect all corrections mentally/in the task list first, then issue exactly
  ONE `Write` per turn.
- Never `Read` the plan file after your own `Edit`/`Write` in the same turn —
  you already have its content in context.
- This exact loop (5 Read + 22 Edit + 3 Write, ~3,900 tok) has now recurred
  identically across 3 sessions despite a MEMORY.md soft guardrail — treat as a
  hard constraint, not a preference. If it recurs again, stop editing the plan
  file entirely mid-session and hold the plan only in TaskCreate/TaskUpdate,
  writing to disk once at ExitPlanMode time.

### ExitPlanMode Load-Bearing Steps

_~2,500 tokens/session saved_

- Before calling `ExitPlanMode`, scan the plan for any step that does a `cd`,
  worktree switch, or settings change and add a one-line note explaining WHY
  it's load-bearing (e.g., "cd reloads worktree-local settings") — not just what
  it does.
- Rejected 3x again this session (msgs 171, 210, 589), same count as prior
  sessions, same root cause: mechanism-critical steps framed as convenience.

### Deletion-Verification Command Pattern

_~300 tokens/session saved_

- After `rm -f <probe file>`, verifying with `ls <file>` reports a nonzero-exit
  "No such file" as an ERROR even though it's the expected success signal (seen
  at msgs 357 and 429, identical pattern both times).
- Use `test -e <file> && echo present || echo removed` instead so the check
  exits 0 regardless of outcome.

### Large Plan Docs — Read by Line Range

_~850,000 tokens/session saved_

- Plan docs under docs/superpowers/plans/ and docs/1-plans/ run 15-60KB and get
  re-Read dozens to 165x per session (task163-wp-l3-service-persistence-plan.md
  alone: 165 reads, ~843K tokens in one session).
- Before re-reading, `grep -n '^#'` for the target heading and Read only that
  line range instead of the whole file.

### Scratchpad Diff/Review Files

_~400,000 tokens/session saved_

- Large diffs written to scratchpad (e.g. pr1414-diff.txt: 126 reads/~375K
  tokens; pr1408-full.dif: 22 reads/~27K tokens) get re-Read repeatedly instead
  of referenced from context.
- After writing a diff to scratchpad, keep needed hunks in conversation or
  `grep -A/-B` the target pattern rather than re-Reading the full file each
  turn.

### Git Worktrees Duplicate Script Reads

_~90,000 tokens/session saved_

- Repo runs many parallel worktrees (.worktrees/child-f,

- Same scripts (rebuild-knowledge-graph.mjs, matrix-schema.mjs, seed-matrix.mjs,

  it actually differs from the already-read root version.
