## Changes

### V2 Core Financial Model (F_2.0.0 Phases 1-5)

New stateless, side-effect-free internal-economics calculation core under
`shared/lib/internal-economics/v2/`. Versioned input contract
(`internal-economics-composite/2.0.0`), refusal-first validation pipeline,
event-stream engine with lot provenance and callable tracking, deal-by-deal and
whole-fund waterfall engines, preferred-return accrual kernel, fee-recycling
enforcer, reserve-funding classifier, and receipt builder with
canonical-json-sha256 hashing. V1 byte-frozen (15-file SHA-256 certification).
No routes, persistence, jobs, migrations, or activation. ADR-085 in
DECISIONS.md.

### F1 Conformance Right-Sizing

Strict `2.0.1` input contract: pre-schema version check catches known-but-wrong
versions before Zod; admission guard blocks event processing in public functions
(`deriveInternalEconomicsV2`, `certifyInternalEconomicsDualLaneV2`) while
allowing `runLane` helper to succeed for future phases. Legacy corpus adapter
transforms 2.0.0 truth-case fixtures into 2.0.1 wire-valid shape (test-only).
Independent test oracle using only `node:crypto` primitives, zero production
imports. Engine test replays all 11 legacy corpus cases through adapter into
derive, verifying correct refusal codes and stages. CI classifier updated for
new financial paths; CI workflow step added for V2 tests.

### Test Coverage

205 V2 tests across 13 test files: 30 normalizer, 12 deriver, 5 lane isolation,
8+8 waterfall (deal-by-deal + whole-fund), 17 fee-recycling, 18
preferred-return, 5 reserve-classifier, 17 event-stream, 6 property tests, 2
benchmarks, 53 corpus adapter, 24 engine truth-case replay.
