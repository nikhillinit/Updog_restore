# Changelog - Week 1, 04-08-2026, V. 1.4.0

**Release Date**: Week 1, 04-08-2026 at 23:07 **Version**: 1.4.0 (previously
1.3.3) **Object**: feat(current-forecast): pre-soak v2 runtime - shadow wiring,
activation latch, resume/re-arm **Code review**:
`docs/3-code-review/CR_w1_v1.4.0.md` (Codex loop, 4 rounds -> APPROVED with
observations)

## Changes

- **Shadow reachability (NEW-A)**: production shadow triggers wired at both
  facts-commit call sites (`financial-facts` route and
  `analysis-checkpoint-service`), with get-or-create baseline receipts,
  exact-basis replay handling, and a single bounded execution race covering mode
  resolution, facts lookup, plan resolution, receipt creation, and replay work.
  Failure persistence is conflict-tolerant (`ON CONFLICT DO NOTHING`) with its
  own five-second cap.
- **Activation gating**: latest-decisive-observation gate (decisive = `failed`
  OR `available` + `match`/`mismatch`, state-qualified) replaces first-failure
  blocking; one-way activation latch (fresh-key repeat activation 409; same-key
  replay 200 `replayed: true`).
- **Resume/re-arm command (#1299-R)**: new authenticated, idempotency-keyed
  admin route recovering from `held` (all causes: `kill_switch`,
  `configured_off`, `configured_shadow`) without repeat activation;
  version-conflict 409, missing `Idempotency-Key` 428; route-policy registry
  entry added.
- **Legacy facade isolation (#1325)**: `current-forecast-serving-seam.ts`
  centralizes `metricsAggregator` consumers (`dual-forecast`, `fund-metrics`,
  `h9-artifact-invalidation-service`); guardrail test enforces seam-only
  consumption.
- **Neon HTTP transaction fallback**: `server/lib/transaction-support.ts`
  exact-error-matched autocommit fallback for `drizzle-orm/neon-http` (Vercel
  prod); pre-existing activation-time transactions deferred to `F_1.2.0`.
- **Flag retirement**: `enable_current_forecast_v2` deleted from the flag
  registry (DB-mode activation only, Decision A).
- **Bounded identities**: idempotency key
  `cfref:{fundId}:{sha256(inputHash+':'+resultHash)}` fits `varchar(128)`;
  `CURRENT_FORECAST_V2_CALC_VERSION = 'cf-v2/1.0.0'` fits `varchar(20)`.
- **Soak evidence**: new runbook `docs/runbooks/current-forecast-shadow-soak.md`
  with deterministic reconstruction SQL; regenerated `docs/_generated/*` router
  indexes.
- **Governance**: ADR-071 (resume/re-arm semantics, latest-decisive-observation
  gating, bounded idempotency key) in `DECISIONS.md`; `CHANGELOG.md` entries for
  all four workstreams.
- **Tests**: 11 test files (new: pg integration for bounded-key insert, resume
  command/route behavior, shadow trigger, checkpoint shadow trigger). Full suite
  11,844 passed; `phoenix:truth` 336; `policy:verify` 140.
